# Ghost Console

Portable Linux cloud and network operations workstation built from salvaged enterprise hardware.

## Hardware
- Dell Latitude 7480
- Intel i7-6600U
- 16GB DDR4 RAM
- Ubuntu Linux
- External 1TB boot drive

## Tooling
- OCI CLI
- Docker
- GitHub SSH
- Networking utilities
- Linux terminal environment

## Purpose
Ghost Console is a portable infrastructure and cloud engineering workstation used for:
- OCI automation
- networking diagnostics
- scripting
- Docker workloads
- infrastructure labs
- cloud operations

## Status
Operational
